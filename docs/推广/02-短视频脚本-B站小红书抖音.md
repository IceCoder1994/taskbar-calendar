# 短视频脚本 · B站 / 小红书 / 抖音

> 用途：面向普通 Windows 用户的短视频与图文笔记脚本。
> 素材：`site/assets/demo-dark.gif`（交互演示）、`calendar-light.png`、`calendar-dark.png`、`settings.png`。
> 唯一官方入口：**官网 calendar.icewang.qzz.io**（口播与文字统一指向官网）。

---

## 一、平台外链策略（重要）

| 平台 | 能否放链接 | 建议做法 |
| --- | --- | --- |
| B站 | 简介可放 | 简介放官网链接；视频内口播"官网见简介" |
| 小红书 | 正文/评论直接外链易限流 | 不写网址，引导"主页简介 / 置顶评论"；或口播"搜索任务栏日历" |
| 抖音 | 普通号不可挂外链 | 口播 + 评论区置顶引导"官网 calendar.icewang.qzz.io" |

> 通用原则：视频内**口播一次**、**评论区置顶一次**、**主页/简介一次**，不重复刷链接。

## 八、拍摄提示

- 录屏用 100% 缩放、系统深色主题，效果最接近演示 GIF；
- 点击时钟前先停 1 秒再点，方便剪辑卡点；
- 面板弹出后可轻微推近镜头，突出「休 / 班」角标；
- 若真人出镜，开头 3 秒先抛痛点再展示工具，完播率更高。
