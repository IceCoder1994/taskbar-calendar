## 正文

### 一、Win11 的日历，总是差那么一点

Windows 11 自带的任务栏时钟，点开是系统日历。它够用，但对我们来说总有几处别扭：

- 24H2 之后，日历默认折叠在通知中心底部，查阅要多点一步；
- 没有传统农历的「初几」「月名」，被问一句"今天农历多少"还得掏手机；
- 没有二十四节气和传统节日（除夕、中秋、端午……）；
- 看不到国务院的放假与调休安排，周末补班常常后知后觉。

### 二、我给它换了一个"点击即弹"的日历

【配图 1】`site/assets/demo-dark.gif` —— 点击任务栏时钟，日历面板平滑弹出的交互演示

任务栏日历（Taskbar Calendar）是一个纯绿色的 Windows 11 小工具。它不替换系统时钟的外观，只是接管"点击时钟"这个动作：点一下，就在时钟上方弹出一个自研的日历面板。

它做了这些事：

- **农历全都有**：农历日期与月名（初一、十五……）、干支、二十四节气、传统节日；
- **调休一眼清**：法定节假日用红字标「休」，周末补班用绿字标「班」，数据自动同步；
- **Win11 原生观感**：Fluent 风格的圆角与微阴影，自动跟随系统深色/浅色模式；
- **不破坏原功能**：通知中心照常可用（点时钟右侧的铃铛，或按 `Win + N`）；
- **极致轻量**：zip 约 500KB，免安装，解压双击即用。

### 四、六个我觉得最实用的点

1. **免安装、零依赖**
   程序基于 Windows 10/11 系统自带的 .NET Framework 4.8 构建，不需要额外安装任何运行库。下载解压、双击即用；卸载直接删文件夹，不留注册表垃圾。

2. **农历、节气、调休一次到位**
   内置公农历换算算法，覆盖 1901–2100 年；节假日数据依据国务院公告，每天后台静默校验更新，离线时使用本地缓存。

3. **深浅色自动跟随**
   系统切深色它就变深色，切浅色它就变浅色，和 Win11 融为一体。

4. **不使用全局鼠标钩子，更安心**
   很多"点击增强"工具依赖全局钩子，容易被杀毒软件误报。这个项目改用纯 Win32 透明点击层，只覆盖时钟那一小块区域，干净、可控。

5. **常驻几乎无感**
   空闲时不占用 CPU，内存占用大致相当于一个浏览器标签页，长期挂着也没有负担。

6. **自带一键更新（新版）**
   检测到新版本时托盘会提示，点一下即可就地下载、替换并重启，不用再手动解压覆盖。

### 五、三步用起来

**第 1 步：下载并解压**
从官网下载 zip（约 500KB），解压到任意目录，例如 `D:\Tools\TaskbarCalendar`。

**第 2 步：双击运行**
运行 `TaskbarCalendar.exe`。若出现 Windows SmartScreen 的"未知发布者"提示，点「更多信息」→「仍要运行」即可（原因见下方 FAQ）。

**第 3 步：点击任务栏时钟**
程序会在托盘常驻。点击任务栏右下角的时钟，日历面板就会弹出来。托盘右键可开启"开机自动启动"。

### 六、常见问题

**Q1：装了它，系统通知中心还能打开吗？**
可以。程序只接管"点击时钟弹出日历"这一行为，通知中心依旧能通过时钟右侧的通知铃铛，或快捷键 `Win + N` 呼出。

**Q2：为什么运行时会提示"未知发布者"？**
因为这是个人开源项目，没有购买商业代码签名证书（每年费用不低）。项目代码已在 GitHub 100% 开源，可自行检阅；介意的话可以先看源码再运行。

**Q3：节假日数据需要手动更新吗？**
不需要。程序内置自动同步，每天后台校验国务院最新安排；断网时也能显示已缓存的节假日。

**Q4：点击位置和我的时钟有点偏差怎么办？**
设置里提供水平、垂直像素偏移微调；多屏等特殊环境还支持"5 秒手动取点校准"。

**Q5：怎么退出或卸载？**
托盘图标右键 →「退出」，然后删除解压出的文件夹即可，绿色无残留。

### 九、技术彩蛋（不关心实现可跳过）

如果你也好奇它是怎么做到"点一下时钟就弹面板"的，实现上主要有几点：

- **定位时钟**：后台通过 UI Automation 读取任务栏时钟按钮的矩形，做了多级兜底（类名候选 + 名称/位置特征 + 类名兜底 + 手动校准），因此能适配不同系统版本、不同语言；
- **接管点击**：用一个纯 Win32 的透明点击层覆盖时钟矩形，收到左键抬起事件即弹面板。刻意没有使用全局鼠标钩子，也不在 WPF 里托管该层（避免分层窗口渲染异常）；
- **保持轻量**：目标框架选在系统自带的 .NET Framework 4.8，整个发布包只有 exe 加少量依赖 dll；
- **自动更新**：内置无窗口批处理，在进程退出后解开文件锁、静默解压覆盖并重新拉起新版。
