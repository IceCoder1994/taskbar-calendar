## 一、推荐发布节奏

1. **第 1 天**：知乎 + 掘金发图文长文（沉淀可被搜索的内容，链接可放）；
2. **第 2–3 天**：B站 / 抖音 / 小红书发短视频（引流为主，注意外链策略）；
3. **第 4 天**：CSDN 同步长文（可微调标题，避免完全重复）；
4. **后续**：每次版本更新可在原帖追加"已更新至 vX.Y.Z"，维持帖子活跃。

> 发帖前先确认官网下载可用：打开官网，点击下载按钮能拿到 zip。

## 三、引流合规红线

- **不刷量、不买赞**：异常数据可能触发平台风控，得不偿失；
- **不在多平台同一时间复制粘贴完全相同的正文**：适当改写开头与标题；
- **不诱导"三连换下载"等违规互动**：各平台对此处罚较严；
- **小红书 / 抖音避免正文直接出现裸网址**：改用"主页简介 / 置顶评论 / 搜索关键词"；
- **不夸大、不绝对化**：避免"最好用""百分百""完全替代"等表述，实事求是。

## 四、常见质疑与应对话术

**Q：提示"未知发布者"，是不是有病毒？**
个人开源项目没有购买商业代码签名证书，所以 Windows 会提示未知发布者。项目基于 MIT License 在 GitHub 完全开源，代码可自行检阅；如不放心可先看源码。

**Q：会收集我的隐私吗？**
程序只做两件事：读取任务栏时钟位置以覆盖点击、联网获取节假日数据。不涉及账号、不采集个人数据。

**Q：装了以后系统日历 / 通知中心还能用吗？**
通知中心完全不受影响，点时钟右侧铃铛或按 `Win + N` 即可呼出。

**Q：收费吗？以后会收费吗？**
免费、开源，基于 MIT License。

**Q：为什么安装包这么小？**
它依赖 Windows 自带的 .NET Framework 4.8，不需要打包运行时，所以压缩包约 500KB。
